# 01 · 技术规范与假设（schema_v1）
> 与总纲 §4/§5/§6 同步；参数唯一来源：`DPA/config/default.yaml`、`DPB/config/default.yaml`。

## 1. 坐标、几何与运动学
- 单位：长度 mm，时间 s，角 deg；欧拉角 ZYX，姿态名义 0。
- 链条位置 s∈[0,450000)；工位 s=0；相对工位 X 坐标 `x_wrap(s)=((s+225000)%450000)−225000`。
- 第 i 钩基准 `s_i(0) = i·450000/700 + δ_i`，`δ_i~TruncN(0,5)`。
- 钩参数：L=100+ε_L (ε~TruncN(0,5))，r=20+ε_r (σ=2/3)，R=5+ε_R (σ=1/3)；截断于 ±公差。
- 局部尖端参考点（apex）：`p_tip=(0, L−R, 2r)`；`tip_ref=center` 改为 `(0,L,2r)`；`arc_plane=horizontal` 时弧在 XZ 平面，轴交换。
- 刚体扰动：δθz~N(0,σ_a²)（Rz），δφ~N(0,σ_a²)（Rx），δψ~N(0,σ_ry²)（Ry），根部平移 δy_root~N(0,σ_y²)；`σ_a=angle_tol_deg/3=1.6667°`。
- 尖端坐标 = `Rz(θz)·Rx(φ)·Ry(ψ)·p_tip + (x_wrap(s_i), δy_root, 0)`；姿态输出 `(φ,ψ,θz)` deg。
- correlated 模式：θz/φ/ψ/δy_root 各为 OU，`u[t+dt]=ρu[t]+σ√(1−ρ²)ε`，`ρ=e^(−dt/τ)`，边缘 σ 不变；white 模式每帧独立。可加共模 `common_mode_ratio`。
- 链速：`v[k+1]=clip(v0+(v[k]−v0)·exp(−dt/τ_v)+σ_v√(1−e^(−2dt/τ_v))ε+event_rate_term,20,80)`；常态 σ_v=1.667 mm/s。
- 事件：泊松 λ=1/120 s；幅度 ±[15,35] mm/s；斜坡 0.5–2 s（线性），稳定段约 2 s，事件期速度噪声 σ=4；`s[k+1]=(s[k]+v[k]dt)%450000`。事件标志写入 truth 与 meta，**不进 DPB 预测路径**。

## 2. DP3000 传感器一级保真度（声明的简化）
非逐点轮廓重建：直接对尖端六维真值加噪声并摘要为 profile 行（每行一个 track 的一帧）。`t_arrival=t_sensor+latency(0.02)+jitter`。位置 σ=0.1 mm、角度 σ=0.3°、量化步长 0.01 mm/0.01°、丢帧 1%、离群 0.2%（0.5 mm/2°）；`sensor_hard` σ_pos=0.5、丢帧 5%。视场 X∈[−700,+100]；只有视场内帧才可见。`track_id=T0001…` 按进入视场次序分配；`eval_only/track_map.csv` 唯一映射，evaluator 专用。

## 3. 因果架构与门控
`truth → sensor_sim（唯一真值读取者）→ sensor_stream.csv → StreamReplayer(t≤t_now) → tracker/predictor/planner → robot_sim → evaluator(truth+track_map)`。
- DPB 包禁止 `import dpa`；测试 grep 禁止符号。
- 预测器输入仅 `SensorFrame(track_id,t_sensor,t_arrival,pose,valid)`；不含 hook_id、真值参数、事件标志。
- 指令时刻 t_issue 只能用 t_arrival≤t_issue 的帧；篡改 t>cut 真值后，t_issue≤cut 的 predictions/commands 必须逐字节相同。
- 兼容性适配层 `tools/adapters.py`：列名别名（如 `time/t/x/y/z/rx/ry/rz`）、单位（m→mm、rad→deg）、track_map 可选时按 track_id 排序映射，并生成转换记录。

## 4. 预测器阶梯
| 版本 | 方法 |
|---|---|
| B0 | 恒速外推：当前速度用最后两帧差分，姿态保持最近值 |
| B1 | 卡尔曼（位置/速度/加速度，标量每轴），姿态 AR(1) |
| B2 | 全链共享速度估计：所有视内 track 的 x 斜率加权平均，事件残差检测 |
| B3（主） | 每钩静态偏置鲁棒均值 + 共享链速 + Y/Z/Rz/姿态 OU 条件均值，τ 在线估计；输出 σ；事件变点检测 |
| B4 | B3 + 自监督 Ridge 残差校正（标签只用已到达传感器帧；实验未晋级） |
| 调度（默认 adaptive） | 在线节拍 cadence∈[11,20] s：单指令 H≈2.2 s（Hook 接近工位时发）；cadence<11（fast）或>20（slow）：首指令+2 s 修正；`two_command`/`single_command` 可单独配 |
| 当前位置估计 | 最近 0.3 s 的 OLS 外推到最新到达时刻，避免中位数造成 0.15 s 滞后（80 mm/s 时 12 mm 偏差） |

X 预测：`x_hat(t)=x_filter(now)+v_hat·Δt`（κ_a 默认 0，因加速度外推会放大事件过冲）；`x_filter(now)` 用最近 0.3 s 的 OLS 外推；v_hat 取全链共享稳健斜率（shared_weight=1.0）。
OU 条件均值：`μ(t)=m_hat+(u_now−m_hat)e^(−Δt/τ̂)`；τ̂ 由该轨历史lag-1回归 + 跨轨池化估计，裁剪到 [0.3,3.0] s。σ_out 用理论下限与在线残差取大。

## 5. 规划与机械臂
- 首指令：hook 进入视场且满足 `0.5+d/200≤H` 后，选目标时刻 `t_meet` = hook 预测 x 最接近 0（工位）的时刻，代价含行程、τ、可观测数据长度；H 限制 [2,10]，且从首条起 ≤10 s。
- 修正：在 `t_meet−2.0 s` 发最后指令（H=2）；事件残差超阈值或首指令 H>4 时可在中间追加一条；避免两指令间隔 <0.6 s。
- 指令有限：新指令在 `t_issue+0.5` 生效；若此时上条尚未 start，取消上条；若正在移动，从当时 TCP 位置转向新目标；直线 200 mm/s，旋转瞬时。
- 可达性：`0.5+d_3D/200≤H`；否则记物理不可达。工作包络 X∈[−300,+300]，Y∈[0,500]，Z∈[−100,300]。
- 相遇检查取最后有效指令的 `t_target`（主）与 ±0.5 s 窗口最小距离（副）。

## 6. 理论下限与上限
- OU 分量预测标准差 `σ(τ,H)=σ0√(1−e^(−2H/τ))`；H=2,τ=1.2 → 0.96σ≈1.60°/2.68 mm 等效位移。
- 位置分量静态 σ：X/Y/Z 由 θz、δy_root、φ 传播；用雅可比 `∂p/∂θz=(−p_y,p_x,0)`、`∂p/∂φ=(0,−p_z,p_y)` 算分量方差；角 σ≈σ_a√(1−e^(−2H/τ))。
- 阈值成功率上限：用上述协方差 MC 采样（默认 200000 次）计算各档 P(‖Δp‖≤p_th ∧ geo(ΔR)≤a_th)；另给"计入链速 OU  forecasts"的上限：`σ_v(H)=σ_v·sqrt(1−exp(−2H/τ_v))·H`，作为更诚实的达成率分母。
- 评估口径补充：SR 分母包含所有有真值记录的挂钩；无指令或目标时刻超出真值导出窗口均计失败（`传感器丢失`），误差统计量仅在可插值挂钩上计算，报告中明示。DPA `export_margin_mm=600` 保证目标点在导出窗口内。
- 完美预测机械臂上限：用真值目标至少一次指令做同一机器人仿真，给出 SR_upper_robot；报告取 min(噪声上限, 机器人上限)。
